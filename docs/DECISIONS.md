# 우리사주 주요 결정 기록

> GPT와 Claude가 다시 논의하지 말아야 할 현재 확정사항. GitHub 최신 `main`과 최신 사용자 지시가 최우선이다.

## 브랜드

- 공식 서비스명: **우리사주**.
- 저장소명, 기존 Vercel 도메인, DB 테이블/저장 버전의 `woorigunghap_*` 등 기술 식별자는 호환성을 위해 유지할 수 있다.
- 레거시 기술 식별자를 사용자 화면의 브랜드명으로 새로 노출하지 않는다.

## 제품/가격

- 1:1: **1,000원**.
- 1:N: **3,000원**.
- 1:N은 핵심 상품이며 제거하지 않는다.
- 관계 유형: 짝사랑 / 썸 / 연인 / 친구 / 직장동료.
- **기존 `/free` 관계 성향 자기분석 상품/UI/API는 2026-08-27 사용자 지시로 폐기한다.**
- `/free`는 **무료 내 천생연분 보기** 입력 플로우로 교체한다. 현재 단계에서는 입력 UI/UX만 구현하며, 사주원국을 토대로 잘 어울리는 사주 팔자를 설명하는 결과 계산/서술 로직은 후속 작업으로 둔다.
- 홈 진입 카드는 `무료 천생연분 → 1:1 궁합 → 1:N 궁합` 순서를 기본으로 한다.

## UI / 디자인 — 2026-08-27 재확정

- 홈 UI의 최우선 기준은 사용자가 2026-08-27 현재 대화에서 첨부하고 `A안`으로 확정한 390px 모바일 레퍼런스 이미지다.
- 사용자는 "가깝게"가 아니라 **99% 동일한 시각 구조**를 요구했다. 과거 `Design Foundation v2`, `JOOTOPI_UI_REDESIGN.md`의 상충하는 홈/입력 UI 규칙은 새 화면 구현 기준으로 사용하지 않는다.
- 홈은 모바일 앱형 단일 컬럼이며 최대 폭 **390px**을 기준으로 한다.
- 홈 핵심 구성: 상단 브랜드/알림 → hero → 무료 천생연분/1:1/1:N 3개 진입 → TOP3 → 관계 흐름 → 주토피 한마디 → 하단 4탭.
- 홈에서는 pastel pink / lavender / butter yellow, rounded cards, 작은 그림자와 gradient를 레퍼런스대로 사용할 수 있다.
- **무료 천생연분 입력, 1:1 입력, 1:N 입력은 2026-08-27 사용자가 첨부한 모바일 폼 레퍼런스를 최우선 기준으로 전면 재구현한다.** 기존 desktop-like 입력 레이아웃은 폐기한다.
- 공통 입력 UI는 이름/별칭 → 성별 → 양력/음력 → YYYYMMDD → 출생시간 24시간제 HHMM → 시간 모름 순서를 기본으로 한다.
- 출생시간은 오전/오후 선택 없이 **24시간제 HHMM**만 사용한다.
- 1:1은 3단계 `내 정보 → 상대방 정보 → 확인` 구조를 유지하면서 시각 구조를 새 레퍼런스에 맞춘다.
- 1:N은 `기본 정보 → 후보 정보 → 확인`, 후보 2~5명 기능을 유지하면서 동일한 모바일 입력 디자인 언어로 재구성한다.
- 캐릭터 원본 asset 최종 교체 전에는 `ZootopiMark`를 임시 렌더 자산으로 사용할 수 있다.

## 리포트

- 1:1은 CH0~CH9 상세 리포트 구조를 유지한다.
- 목표 분량은 공백 제외 대체로 2,500~4,000자.
- 문체 취향·재미·일부 반복은 그 자체로 blocker가 아니다.
- 유료 리포트는 일상 언어의 관계 결론/장면 → 사주 용어와 계산 근거 순으로 설명한다.
- 서버 근거 없는 사실·숫자·미래 시기·숨은 심리를 새로 만들지 않는다.
- 1:N은 전체 ranking → 후보 역할 → 공통 지표 비교 → 후보별 강점/주의점 → 상세 후보 리포트 순서를 유지한다.

## 계산 / AI

- 사주·궁합 계산은 서버 결정론 로직이 수행한다.
- AI는 계산 결과를 바꾸지 않고 서술만 생성한다.
- 유료 1:1·1:N 서술 기본 모델은 `claude-sonnet-5`.
- 이름/원본 생년월일시는 외부 AI에 직접 전달하지 않는다.
- 결제가 서버에서 검증된 뒤에만 유료 AI 생성을 실행한다.
- 동일 결제/세그먼트 AI 중복 호출을 막는 single-flight/idempotency를 유지한다.
- 저장된 기존 구매 결과는 임의 재생성하지 않고 저장 결과를 재열람한다.
- 무료 천생연분 결과 로직은 아직 미구현이며, 구현 시 기존 deterministic 만세력 snapshot을 입력 근거로 사용하고 외부 AI에 원본 개인정보를 직접 전달하지 않는 원칙을 유지한다.

## 저장 / 계정 / 보안

- 서버 DB(Neon)가 주문·결제·완성 결과의 권위 데이터다.
- 브라우저 저장소는 재개/복구 보조 사본이다.
- 결과 접근 토큰 원문은 서버에 저장하지 않고 SHA-256 해시를 사용한다.
- Kakao 로그인은 선택형이며 비회원 결제 흐름을 유지한다.
- 계정 소유권 검증 없이 유료 결과를 열람하게 만들지 않는다.
- 회원탈퇴·결과 삭제 시 정의된 삭제 대상 데이터 정리 원칙을 유지한다.
- 비밀값은 코드·로그·문서·GitHub에 커밋하지 않는다.

## 결제 / 운영

- PortOne 서버 검증 이전 유료 결과 생성 금지.
- webhook 및 주문 처리는 멱등성을 유지한다.
- 1:1 / 1:N 가격·상품 ID·금액 검증을 서버 권위로 유지한다.
- Vercel Git 자동배포는 기본 비활성화한다.
- Preview/Production 배포는 사용자 명시 승인 후 수행한다.
