# Growth P2 Raw Share Copy Review v1

> 상태: **REVIEW ONLY**. 이 문서는 Production 공유 카드에 연결되지 않습니다.
> 목적: 사용자가 P2 raw 240개 후보를 직접 `채택 / 보류 / 제외`로 선별하기 위한 검토본입니다.

## 선별 방법

- 답변 예시: `채택: CR-ST-01, CR-ST-03 / 보류: CR-ST-02 / 제외: CR-ST-04`
- 한 번에 전부 고를 필요 없이 관계 유형별·패턴별로 나눠서 검토합니다.
- 최종 목표는 240개 raw 중 120~160개를 Production 후보로 확정하는 것입니다.
- 현재 문구에는 실제 사용자 이름, 생년월일시, 결제/접근 토큰, 유료 본문이 포함되지 않습니다.

## 평가 기준

1. 실제 공유하고 싶은가
2. 자연스러운가
3. 해당 관계 유형답게 구체적인가
4. 계산 패턴에 연결하기 쉬운가
5. 다음 내용을 궁금하게 만드는가
6. 오글거리거나 과장되지 않았는가

## 톤/용도

- `clean`: 가장 넓게 쓰는 기본형
- `tease`: 가볍게 놀리는 공유형
- `curiosity`: 일부를 남겨 클릭/반응을 유도하는 호기심형
- `relationship_label`: 관계를 한 문장으로 규정하는 카드
- `two_sides`: 강점 + 조율 포인트용
- `send_this`: 상대에게 바로 보내기 좋은 카드
