# 우리사주 Day 9 — Claude 서술·원가 정책 (폐기됨)

이 문서는 2026-08-12의 초기 단일 호출/짧은 서술 구조를 기록한 과거 문서이며 **현재 구현 기준으로 사용하지 않는다.**

현재 운영 기준은 다음 문서를 단일 기준으로 사용한다.

- `docs/ai-narrative-cost-policy.md` — Claude 모델, v7 분할 호출, 실제 원가 추정, 재시도 원가 정책
- `docs/paid-report-content-contract.md` — 사주팔자/오행 기본정보, 필수 10개 챕터, 장문 분량·품질·재개 정책

## 폐기된 내용

아래 초기 정책은 현재 적용하지 않는다.

- 1:1 리포트 AI 1회 호출
- `headline / summary / strengths / adjustments` 위주의 짧은 출력 스키마
- 2,500 input + 900 output을 전체 유료 리포트의 대표 원가로 사용
- Structured Output을 장문 생성의 기본 경로로 사용
- API 오류 시 짧은 template narrative를 유료 최종 결과로 즉시 대체
- 지연 시 사용자가 수동으로 다시 생성하도록 안내

## 현재 핵심 원칙

- 점수·순위는 서버 결정론 엔진이 확정하고 Claude는 변경하지 않는다.
- 이름, 원본 생년월일시, paymentId/orderId는 Claude에 전달하지 않는다.
- 1:1 장문 결과는 `intro / dynamics / action` 3개 세그먼트로 나누어 생성한다.
- 세운·대운·특정 연도/월 관계 타이밍은 제공하지 않는다.
- 완료된 세그먼트는 저장하고 일시 오류가 발생한 세그먼트만 자동 재시도한다.
- 단순 분량 미달만으로 정상 구조 응답을 폐기하지 않는다.
- Claude JSON은 서버에서 재귀적으로 스키마 검증한 뒤 UI에 전달한다.
- 지연·네트워크·서버/Claude 일시 오류는 사용자 화면을 실패 상태로 바꾸지 않고 완료될 때까지 재개한다.
- 인증·크레딧·권한·결제 불일치처럼 기다려도 해결되지 않는 오류만 중단한다.
