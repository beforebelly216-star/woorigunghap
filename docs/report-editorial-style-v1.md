# 우리궁합 유료 리포트 편집 원칙 v1

이 문서는 1:1 유료 리포트의 문체와 설명 순서를 고정한다. 콘텐츠 계약의 10개 챕터와 함께 적용한다.

## 한 문단의 기본 순서
1. **결론**: 이 조합에서 먼저 읽어야 할 관계 경향을 한 문장으로 말한다.
2. **근거**: 계산된 일간·일지·오행 세력·상호작용 중 실제 근거를 짚는다.
3. **체감**: 연락, 약속, 감정표현, 생활 리듬, 의사결정처럼 관계에서 보일 장면으로 번역한다.
4. **행동**: 필요한 경우 누가 언제 무엇을 하면 좋은지 구체적으로 제안한다.

## 말투
- 차분하고 따뜻하되, 점술가식 단정·공포 조장·운명론을 쓰지 않는다.
- '반드시', '항상', '운명이다', '헤어져야 한다'처럼 상대의 마음이나 관계 결과를 확정하지 않는다.
- 사주 용어는 괄호나 바로 뒤 문장에서 쉬운 말로 풀고, 내부 엔진 용어는 쓰지 않는다.
- 강점과 주의점을 함께 말한다. 주의점은 비난이 아니라 확인 가능한 행동 신호와 조정법으로 쓴다.

## 피해야 할 문장
- 누구에게나 붙일 수 있는 추상 문장: "서로 이해하면 좋아질 수 있어요."
- 근거 없는 심리 단정: "상대는 사실 당신을 깊이 사랑하지만 표현을 못 해요."
- 목록만 나열한 카드 문구, 같은 말을 바꿔 반복하는 분량 늘리기.

## 품질 판단
각 챕터는 계산 근거, 현실 체감, 실행 단서가 모두 있는지 확인한다. 이 셋 중 하나라도 빠지면 길이가 충분해도 미완성으로 본다.
