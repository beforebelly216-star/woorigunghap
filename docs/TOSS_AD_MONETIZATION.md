# 우리사주 앱인토스 광고 수익 전환 — 2026-10-02

사용자 결정: 미니앱 유료 결제 제거, 광고로만 수익화. IAP 출시 준비/SKU 등록을 중단한다. 기존 웹 구매 결과/결제 검증/계정은 보존한다. 미니앱의 기본 분석은 무료, 추가 AI 상세 해설은 명확한 선택형 보상 광고로 제공하는 방향이다. 광고 수익이 AI 비용을 충당한다는 가정은 하지 않는다.

## 배치

| 화면/행동 | 광고 |
| --- | --- |
| 홈 | 서비스 목록과 떨어진 본문 배너 1개 |
| 무료 기본 결과 | 결과 본문 하단 배너 1개, 화면 이식 후 연결 |
| 상세 해설 추가 | 명확한 ‘광고 보고 상세 해설 보기’ 선택형 보상 광고 1회, 결과/서버 연결 후 활성화 |
| 결과 확인 후 새 분석 시작 | 자연스러운 전환 시 전면 광고, 기본 결과/뒤로가기 접근을 차단하지 않음 |
| 보관함 | 실제 저장 결과가 있는 로그인 사용자에게 본문 배너 1개 |
| 입력/로그인/약관/탈퇴/오류/공유 | 광고 없음 |

고정 배너를 하단 탐색 메뉴나 분석 버튼에 붙이지 않는다. 동일 화면에 동일 포맷 광고를 2개 이상 배치하지 않는다. SDK 광고 디자인·Ad 표시를 유지한다. 광고 클릭에 보상을 주지 않는다. 주기적인 강제 새로고침/성과 이벤트 조작/뒤로가기 차단을 하지 않는다.

전면 광고 초기 운영값: 최근 전면·보상형 노출과 2분 이상 간격, 30분당 전면형 최대 2회(현재 메모리 세션 기준). 토스 정책이 정한 ‘승인 보장 빈도’가 아니며 실기기 및 이탈/수익 지표로 조정한다. 무작정 모든 화면 전환에 광고를 띄우지 않는다.

## 구현 상태와 설정

- 2026-10-03 사용자 제공 운영 ID 등록: 배너 `ait.v2.live.732b6817f34e4c8f`, 전면 1차 `ait.v2.live.6389f70518ed4f97`, 전면 2차 `ait.v2.live.2ba69cd75b514ab9`. 사용자 답변으로 전체 화면 두 ID 모두 **전면형**임을 확인했다. 1차는 기본 전면에 연결, 2차는 후속 배치용 보관이며 자동 fallback/연속 재생하지 않는다. 보상형 ID는 아직 없으므로 보상형에 전면 ID를 연결하지 않는다. 테스트에서는 운영 ID를 차단하고 개발 번들의 광고 OFF 유지.

- 2026-10-03 QA: 입력 3단계/확인·결과 구성 미리보기·광고 1회 추가 해설 세 주제 묶음 UI 추가. 실제 생성/개인화/보상 지급은 미연결. 기본 결과는 시청 없이 제공하고 배너 표시 가능 조건을 안내한다. 점검/원가/다음 구현: `TOSS_QA_AND_CLAUDE_AUDIT.md`.

- `ad-client.js`: 공식 SDK initialize/attachBanner, load→loaded→show 순서, 중복 실행 방지, 취소/실패/시간 초과, userEarnedReward만 보상 인정, 전면형 placement/간격/횟수 제한. 자동 광고 재시도 없음.
- `ad-components.jsx`: 홈/실제 보관함 단일 배너 수명 관리, 지원 여부 확인, 미설정/No Fill 영역 숨김. 광고 ID가 없는 현재는 기본 OFF다. 실제 분석 기능을 먼저 이식하고 실기기 테스트한다.
- `.env.example`의 VITE_ADS_ENABLED, VITE_ADS_TEST_MODE와 유형별 광고 그룹 ID 사용. 개발에서는 운영 광고 ID를 사용하지 않는다. 배너 공식 테스트 ID는 ait-ad-test-banner-id. 전면/보상형 테스트 ID는 각 포맷에 맞는 공식 ID를 확인하여 설정한다.
- 필요한 값은 토스 콘솔의 배너·보상형·전면형 **광고 그룹 ID**다. 비밀 API 키는 VITE_ 또는 채팅에 넣지 않는다.
- 결과 화면/추가 해설/전면형 트리거는 아직 미연결이다. 분석 완료 전에는 광고 버튼을 활성화하지 않는다. 광고 이벤트만으로 기존 유료 AI endpoint의 결제 검증을 우회하지 않는다.
- 광고 기반 리포트 생성에는 별도 서버 주문/보상 근거/요청 한도/멱등 저장·복구 설계가 필요하다. 클라이언트 earned boolean은 고비용 AI 생성의 서버 권한 증명이 아니다. 같은 결과 재열람에는 다시 광고를 요구하지 않는다.
- 무료 전환만으로 개인정보처리방침·사업자/정산·고객지원 요건이 사라진다고 판단하지 않는다. 기존 로컬 판매 약관 초안은 새 광고형 서비스 기준으로 정리하며 입력된 운영자 정보를 자동 공개하지 않는다.
