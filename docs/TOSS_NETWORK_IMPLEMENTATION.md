# 토스 참여자 네트워크 구현 — 2026-10-05

## 이번에 연결한 흐름

`/one-to-many`: 내 정보 → 토스 로그인 → 공개 동의 → 생성/초대 참여 → 전체/내 관계 → 선택한 두 사람의 무료 기본 결과.

- POST `/api/toss/network`의 create/join/list/view/pair/leave/close는 정확한 토스 Origin과 서버가 확인한 토스 계정만 사용한다. 본문은 8KB로 제한하며 사용자 ID/권한/풀매수 키를 클라이언트에서 받지 않는다.
- 기존 웹의 링크 기반 네트워크와 다른 테이블을 사용한다. 초대 토큰은 가입에만 사용하며 링크 소지만으로 별칭/관계/생년정보를 조회할 수 없다. 참여한 계정은 모든 공개 동의 참여자의 쌍을 볼 수 있다. 네트워크 관계 유형은 친구다.
- 동의 버전/시각과 계정별 하나의 참여 기록, 정규화한 입력의 HMAC 버전을 저장한다. 출생정보는 전용 키로 AES-256-GCM 암호화하고 복호화 시 입력 버전과 일치하는지 확인한다. 원본 생년정보·계정 ID·암호문·입력 버전은 공개 응답에 포함하지 않는다.
- 생성 재시도는 계정+요청 ID로 복구하고 입력 변경은 충돌로 처리한다. 최대 12명, 방장당 활성 네트워크 5개. 생성은 계정 행, 가입은 네트워크 행을 잠근다. 입력 수정은 현재 미지원이며 나가기/새 네트워크가 필요하다.
- 참여한 네트워크 목록을 서버에서 다시 불러올 수 있다(최근 50개). 상세 기본 결과는 기존 엔진으로 요청 시 계산하고, 개인 메모리에만 유지한다. AI/결제/지갑 차감은 실행하지 않는다.
- pair의 서버 내부 스냅샷은 네트워크 ID+정렬된 두 참여자 ID/입력 버전+친구+엔진/점수/서술 버전으로 구성한다. 다른 참여자가 추가돼도 기존 두 사람의 키는 바뀌지 않는다. API 응답은 스냅샷 없이 기본 결과만 반환한다. 향후 생성 완료 시에도 권한을 다시 확인해야 하며 현재 Claude/항목 사용과 연결하지 않았다.
- 모든 참여자가 초대 링크를 공유할 수 있다. SDK `Share.createLink`/`Share.sendMessage`를 사용하며 원래 intoss/intoss-private 스킴과 테스트 deployment ID를 유지한다. 공유에는 초대 토큰만 포함하고 생년정보/별칭/계정 ID는 포함하지 않는다. 실제 토스앱 링크 수신/공유 시트 검증은 남았다.

## 나가기·만료·연결 해제

- 참여자는 자신의 정보 삭제/나가기를, 방장은 전체 네트워크 삭제를 선택한다. 앱에 확인 화면을 둔다. 제거된 참여자는 다음 조회부터 접근할 수 없고 해당 쌍도 선택할 수 없다. 방장 삭제 시 참여자 데이터는 cascade로 삭제한다. 삭제 후 같은 요청 ID로 다시 만들어도 이전 초대 토큰은 재사용되지 않는다.
- 네트워크는 생성 후 30일에 조회/참여가 차단된다. 기존 인증된 cron에 만료 네트워크/출생정보 삭제를 연결했다. 실제 운영 cron 실행은 미검증이다.
- 검증된 토스 연결 해제 콜백은 세션을 폐기하고 해당 계정의 네트워크 참여 정보를 삭제한다. 방장이라면 소유 네트워크 전체를 삭제한다. 기존 웹 회원탈퇴의 토스 제공자 분기에도 같은 정리를 추가했다. 구매 원장/결과는 이 모듈이 삭제하지 않는다.
- 새 키로 교체하면 이전 암호문과 초대 링크를 복구할 수 없다. 키 교체/입력 수정/네트워크 기한 연장/참여자 강제 삭제는 이번 구현 범위가 아니다.

## 검증과 활성화 경계

- PGlite 실제 Postgres SQL: 동의/계정 접근/타 참여자 쌍/점수 일치/개인정보/무결성/대소문자 ID 정규화/재시도/12명/생성 제한/rollback/나가기/삭제/만료/토스 제공자 정리 PASS. 단일 PGlite 연결 테스트이며 Neon 다중 세션 경합/부하는 미검증이다.
- handler: 토스 인증/다른 제공자/Origin/OFF/동의/본문 제한/비공개 스냅샷 제외 PASS. 빌드 HTTP exact Origin preflight204/외부403·미인증/가짜 Bearer401 PASS.
- 기존 무료 결과·원장·토스 로그인/세션/IAP·웹 네트워크 회귀 PASS. 기존 웹 네트워크 테스트의 과거 홈 카드 순서만 현재 확정 디자인에 맞춰 갱신했다. 웹 홈 코드는 변경하지 않았다.
- Chrome 게스트 입력 화면 360/390/430/1280px overflow 없음, 생성/초대 모드/입력 유지·미설정 로그인 비활성 확인. 실제 로그인 참여/공유는 실기기 검증 필요.
- `APPS_IN_TOSS_NETWORK_ENABLED=false` 기본. DATABASE_URL, 32자 이상 NETWORK_PII_ENCRYPTION_KEY, 토스 로그인/mTLS/정확한 서버 URL·실기기·동의/정책 확인 후 활성화한다. 운영 DB/콘솔/배포 변경 없음.
- 후속 배치에서 권한 스냅샷/항목 사용·짧은 Claude/일일 시도 한도·완료 SQL 권한 검사·개인 저장/IAP 검증 지급을 연결했다. 최신 범위/환불·보관·실기기 차단 항목은 TOSS_FULLBUY_IMPLEMENTATION.md.
