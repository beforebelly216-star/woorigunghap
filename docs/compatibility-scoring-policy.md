# 우리궁합 궁합 계산·배점 기준 v1.2

기준일: 2026-08-12  
상태: Day 6 구현 기준 / 결정론 엔진

## 1. 핵심 원칙

- 궁합 점수는 **AI가 아니라 서버의 규칙 엔진**이 계산한다.
- 같은 입력 + 같은 계산 버전 + 같은 관계 프로필이면 같은 결과를 반환한다.
- AI는 최종 점수와 근거를 자연어로 설명할 수만 있고 점수를 변경할 수 없다.
- 명리에서 해석이 갈리는 부분은 억지 정밀화보다 **중립값/낮은 confidence**를 사용한다.
- 점수는 관계 성공확률이 아니라 사주 원국 규칙에 따른 참고용 관계 적합도다.

## 4. 항목별 v1.2 산식

### ① 일간 상성

두 일간의 오행 생극 관계만 평가한다.

- 상생: 85
- 동일 오행: 70
- 상극: 55

방향성과 음양은 evidence로만 저장한다. 천간합과 용신 효과는 다른 항목에서 계산해 중복을 막는다.

### ② 일지 상성

일지↔일지 직접 관계만 평가한다.

- 육합(六合): 90
- 직접 관계 없음: 70
- 해(害): 60
- 형(刑): 55
- 충(沖): 45

복수 관계 우선순위는 `충 > 육합 > 형 > 해 > 중립`. 파(破)는 ②에서 제외하고 ⑥에서 처리한다. ⑥에서는 일지↔일지 쌍을 다시 가감하지 않는다.

### ③ 용신·기신 부합도 — soft signal v1

MVP에서 용신을 학파별 세부 규칙까지 억지로 하나로 확정하지 않는다.

1. `得令(득령) 35% + 得地(득지) 30% + 得勢(득세) 35%`로 신강약 방향 지수를 만든다.
2. 신약 후보는 인성/비겁 방향, 신강 후보는 식상/재성/관살 방향을 중심으로 필요한 오행 후보를 만든다.
3. 중화/경계 사례는 부족 오행 중심으로 보완 후보를 잡는다.
4. 상대 원국이 그 후보 오행을 얼마나 제공하는지 A→B, B→A 양방향으로 계산한다.
5. 신강약 confidence가 낮을수록 결과를 **70점 중립 방향으로 감쇠**한다.
6. 양방향 점수 평균을 ③ 정규화 점수로 사용한다.

즉 신강약 한 번의 오판으로 20점이 극단적으로 뒤집히지 않도록 설계한다.

현재 신강약 지수는 사용자에게 절대 강도값으로 노출하지 않는다. 상세 검증 원칙은 `docs/strength-validation-plan.md` 참조.

### ④ 오행 상보성

표면 오행 개수만 세지 않고 천간 + 지장간을 사용한다.

- 각자의 오행 분포가 얼마나 치우쳤는지 계산
- 두 사람을 합쳤을 때 오행 불균형이 줄어드는지 계산
- 합친 분포가 균형에 가까울수록 높게 평가
- 서로의 편중을 실제로 보완하면 추가 반영

정규화 범위는 55~95로 제한한다.

### ⑤ 천간 합충

두 원국의 천간 교차쌍을 비교한다.

- 오합: 甲己(갑기), 乙庚(을경), 丙辛(병신), 丁壬(정임), 戊癸(무계)
- 충 후보: 甲庚(갑경), 乙辛(을신), 丙壬(병임), 丁癸(정계)
- 일주/월주 위치는 년주/시주보다 약간 크게 반영
- 기본 70에서 합은 가점, 충은 감점
- 45~90 범위로 제한

①의 생극 관계는 여기서 재점수화하지 않는다.

### ⑥ 지지 형충파해

두 원국의 지지 교차쌍을 비교하되 ②에서 이미 계산한 **일지↔일지 쌍은 제외**한다.

기본 70을 중심으로 다음 강도를 사용한다.

- 육합: +4
- 충(沖): -6
- 형(刑): -4
- 해(害): -3
- 파(破): -2

일주/월주 위치를 조금 더 크게 반영하고 결과는 40~90 범위로 제한한다.

### ⑦ 신살·귀인·공망

MVP에서는 신살을 많이 넣어 허위 정밀도를 만들지 않는다.

- v1.2 점수화 대상: **天乙貴人(천을귀인)**만
- 상대 원국에 내 천을귀인 지지가 있으면 보수적으로 가점
- 기타 신살·공망은 evidence/후속 고도화 대상으로 남김
- 정규화 60~85

### ⑧ 배우자성 실체화

Day 2의 `성별을 궁합 원점수에 직접 사용하지 않는다`는 원칙을 유지한다.

romance에서만 10점 배점을 가지며, 전통적인 `남=재성 / 여=관성` 단정 대신 **성별 비의존 관계역할 proxy**를 사용한다.

- 상대 원국에 내가 관계 역할로 사용하는 재성/관성 방향 오행이 어느 정도 존재하는지 양방향 계산
- 평균을 정규화
- 55~85 범위

friend/coworker에서는 배점이 0이므로 총점에 영향이 없다.

### ⑨ 대운 동조

현재 MVP 만세력 모듈은 대운(大運)을 계산하지 않는다.

따라서 존재하지 않는 계산을 꾸며내지 않고 **정규화 70 중립값**을 사용한다. 배점은 기존 100점 스키마 호환을 위해 유지하고, 실제 대운 엔진이 추가되면 계산 버전을 올려 교체한다.

## 5. 출생시간 미상 v1.2

시간 미상자를 고정 중립점으로 대체하지 않는다.

- 기본적으로 子~亥 12개 시주 대표 시각을 모두 계산한다.
- 한 명 미상: 기본 12개 시나리오
- 둘 다 미상: 기본 144개 조합
- 입춘/절입 경계일에서 하루 안에 년주·월주가 바뀌면 00:01/23:59 경계 상태를 추가한다.
- 각 항목 대표값은 시나리오 **중앙값**을 사용한다.
- 전체 시나리오 총점의 최소~최대를 `uncertaintyRange`로 저장한다.
- 범위 폭 0~3: high / 4~8: medium / 9 이상: low confidence

원본 입력에는 임의 시주를 저장하지 않는다.

## 6. 점수 노출

- 내부 계산은 소수점을 유지한다.
- 사용자 종합점수는 마지막에 정수화한다.
- 노출 범위는 30~100.
- 등급: S 90~100 / A 80~89 / B 70~79 / C 60~69 / D 50~59 / E 40~49 / F 30~39.

## 8. MVP 검증 원칙

Day 15 전에는 검증을 과도하게 확장하지 않는다.

- 10건 자동 sanity check
- 24~36건 참조 사례로 큰 방향 반전 여부 점검
- 경계 사례는 confidence 감쇠
- 동일 입력 반복 동일성 100%
- 100건 이상 Gold set / 대규모 구조 stress test는 베타 이후 고도화
