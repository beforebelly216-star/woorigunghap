# 우리사주 무료 1:N 인연 네트워크 명세

## 목적

방장이 자기 정보만 입력해 링크를 만들고, 링크를 받은 사람들이 각자 자기 정보를 입력하면 모든 참여자 사이의 궁합을 인물 네트워크로 탐색하는 무료 유입 기능이다. 정밀 서술이 필요한 두 사람은 유료 1:1 궁합으로 연결한다.

궁합 산식과 출생시간 미상 처리의 권위 기준은 [`compatibility-scoring-policy.md`](./compatibility-scoring-policy.md)다.

## 제품 계약

- 가격: 무료
- 참여 인원: 방장 포함 최대 12명
- 계산 범위: N명의 모든 고유 쌍, 총 `N(N-1)/2`개
- 계산 프로필: 모든 쌍에 동일한 `friend` 관계 기준
- 실시간성: 4초 polling + `graphVersion` 기반 ETag
- 보관기간: 생성 30일 뒤 조회 차단, 일일 자동 정리에서 삭제
- AI: 사용하지 않음
- 신규 유료 1:N 주문: 410 응답 후 무료 네트워크 안내
- 레거시 유료 1:N: 기존 3,000원 구매 결과·복구·공유·저장 호환만 유지

## 사용자 흐름

1. 방장은 별칭과 자기 생년정보, 공개 범위 동의를 입력한다.
2. 서버는 불투명 방 식별자와 별도의 방장·참여자 권한을 발급한다.
3. 방장은 권한 fragment를 제거한 초대 링크만 공유한다.
4. 방문자는 별칭과 자기 생년정보를 직접 입력하고 공개 범위에 동의한다.
5. 서버는 기존 참여자 전원과 새 참여자의 관계를 기존 결정론 1:1 엔진으로 계산한다.
6. 모든 방문자는 별칭, 총점, 등급, 사용자용 강점·조율 축을 인물 네트워크에서 탐색한다.
7. 방장은 참여 열기/닫기, 참여자 제거, 방 삭제를 할 수 있고 참여자는 자기 정보와 관계선을 삭제할 수 있다.
8. 선택한 관계를 더 깊게 보고 싶으면 유료 1:1 입력으로 이동한다.

## 점수와 등급

서버가 계산한 공개 종합점수 30~100을 그대로 사용한다. 방 안에서 S나 E를 억지로 만들기 위한 상대평가·분포 보정은 하지 않는다.

| 등급 | 점수 |
|---|---:|
| S | 90~100 |
| A | 80~89 |
| B | 70~79 |
| C | 60~69 |
| D | 50~59 |
| E | 30~49 |

등급과 관계선 payload에는 계산 엔진·scoring·등급 정책 버전을 함께 고정한다. 저장된 관계를 읽을 때는 저장 당시 grade를 사용하며, 버전이 달라진 기존 방에는 새 참여를 받지 않는다.

## 공개 응답

공개 가능:

- 방장/참여자 별칭과 불투명 member ID
- 방장 여부
- 두 member ID, 총점, E~S 등급, 점수 범위
- 사용자용 강점 축과 조율 축
- 계산 버전, 참여 인원, graph version, 참여 가능 상태

공개 금지:

- 성별, 양력·음력, 생년월일, 출생시간, 윤달 여부
- 암호문, 원시 만세력·궁합 근거, 내부 원점수
- 방장·참여자 권한, 생성/갱신/만료 시각
- IP 주소 또는 rate-limit scope 원문

## 저장·보안

- 생년정보는 Production의 전용 `NETWORK_PII_ENCRYPTION_KEY`에서 파생한 AES-256-GCM 키로 암호화한다.
- Production에서는 결제 webhook secret을 암호화 fallback으로 사용하지 않는다.
- 방장·참여자 token 원문은 브라우저만 보유하고 서버에는 hash만 저장한다.
- idempotency 입력 결합값과 요청 남용 방지 식별값은 전용 키 기반 HMAC으로 저장한다.
- 생성·참여 요청은 동일 origin, 크기 제한, rate limit, 멱등성 검증을 적용한다.
- 동시 참여는 방 단위 PostgreSQL advisory transaction lock으로 최대 인원을 직렬화한다.
- pending 참여는 30분, rate-limit 식별값은 마지막 요청 후 최대 1일 보관한다.

## 화면 계약

- SVG network는 노드와 모든 관계선을 표시하고 선택 인물/S·A/전체 필터를 제공한다.
- 노드 선택 시 해당 인물의 연결을, 관계선 선택 시 두 사람의 총점·등급·강점·조율 축을 보여준다.
- 방장 기준 순위와 선택 인물의 모든 연결을 함께 제공한다.
- 무료 점수가 친구·지인 관계 기준임을 명시한다.
- 입력 지점에서 이용약관과 개인정보처리방침을 바로 열 수 있어야 한다.
- 공유 URL에는 URL fragment와 방장·참여자 권한을 절대 포함하지 않는다.

## 운영 환경과 검증

필수 Production 환경값:

- `DATABASE_URL` — CREATE/ALTER/INDEX 권한 포함
- `NETWORK_PII_ENCRYPTION_KEY` — 첫 방 생성 전 안정된 전용 값
- `CRON_SECRET` — Vercel Cron 인증

완료 조건:

1. 생성 201 → 두 번째 참여 201 → members 2 / edges 1이 된다.
2. N명에서 관계 수가 정확히 `N(N-1)/2`이고 중복 관계가 없다.
3. 실제 결정론 fixture로 S와 E가 모두 도달 가능하고 반복 실행 결과가 동일하다.
4. 공개 JSON에 금지 필드가 없고 공유 링크에 권한이 없다.
5. ETag 304, 참여 열기/닫기, 참여자 자기삭제, 방장 제거·방 삭제가 동작한다.
6. 만료 방 조회가 차단되고 인증된 cron이 만료·pending·rate-limit 데이터를 정리한다.
7. 기존 유료 1:N 결과·복구 경로는 유지되고 신규 주문만 무료 화면으로 전환된다.
