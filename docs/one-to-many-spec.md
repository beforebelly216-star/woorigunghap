# 우리궁합 1:N 비교 상품 구현 명세

## 목적
한 명의 기준 인물과 여러 비교 대상의 궁합을 같은 기준으로 계산해, 단순한 1:1 리포트 반복이 아니라 "누구와 어떤 관계에서 더 잘 맞는지"를 비교해 보여주는 1:N 전용 결과를 제공한다.

## 상품 기본값
- 상품키: `oneToMany`
- 가격: 3,000원
- 기준 인물: 1명
- 비교 대상: 최소 2명, 최대 5명
- 지원 관계 유형: 연인 / 친구 / 직장동료
- 한 주문에서는 하나의 관계 유형만 선택한다.
- 1:N 결과는 1:1 상세 리포트를 N개 붙이는 방식이 아니라 비교·랭킹·차이 중심의 별도 포맷을 사용한다.

## 입력
### 기준 인물
- 이름 또는 별칭
- 성별
- 생년월일
- 출생시간(모름 허용 여부는 만세력 모듈 정책과 동일)
- 양력/음력

### 비교 대상
각 대상마다 동일한 출생정보를 받는다.
- 이름 또는 별칭
- 성별
- 생년월일
- 출생시간
- 양력/음력

## 계산 원칙
- 모든 대상은 동일한 만세력/궁합 계산 엔진과 동일 버전으로 계산한다.
- AI는 사주 원국이나 궁합 점수를 임의 계산하지 않는다.
- 서버 계산 결과를 `calculationSnapshot`으로 고정한 뒤 AI는 설명 문장만 생성한다.
- 동일 입력과 동일 계산 버전이면 비교용 원시 점수는 재생성해도 같아야 한다.

## 공통 비교 지표
각 대상에 대해 0~100 점수로 정규화한다.
1. 종합 궁합
2. 소통 궁합
3. 정서 궁합
4. 갈등/마찰 적합도
5. 지속성·안정성

관계 유형별 추가 지표:
- 연인: 끌림/연애 텐션, 생활 궁합
- 친구: 편안함, 신뢰/의리
- 직장동료: 협업 효율, 역할 보완성

## 1:N 결과 화면 구성
### 1. 한눈에 보는 순위
- 종합 점수 기준 1위~N위
- 대상별 종합점수
- 관계 유형에 맞춘 한 줄 요약
- 점수 차이가 작으면 과도한 우열 표현을 피하고 "비슷한 수준"으로 표시

### 2. 비교 매트릭스
행: 비교 대상
열: 공통 지표 + 관계 유형별 추가 지표

사용자는 어떤 사람이 어떤 영역에서 강한지 한 화면에서 볼 수 있어야 한다.

### 3. 대상별 강점/주의점
각 대상마다:
- 가장 잘 맞는 포인트 2개
- 가장 부딪히기 쉬운 포인트 1~2개
- 관계를 잘 굴리는 실용 팁 1개

### 4. 상황별 추천
점수 하나로 전체 관계를 결정하지 않고 상황에 따라 구분한다.
예:
- 대화가 가장 편한 사람
- 감정적으로 안정적인 사람
- 오래 가기 좋은 사람
- 갈등 관리가 쉬운 사람
- 관계 유형별 핵심 목적에 가장 잘 맞는 사람

### 5. 최종 비교 요약
- 종합 1위
- 각 대상이 특히 좋은 상황
- 기준 인물이 관계에서 주의할 공통 패턴
- "누가 절대적으로 더 좋은 사람"이라는 표현은 금지하고 궁합 맥락으로 한정

## 랭킹 규칙
- 기본 랭킹은 서버 계산 종합점수로 결정한다.
- AI가 순위를 변경할 수 없다.
- 동점 또는 근소 차이 정책:
  - 0~2점 차이: 사실상 동급
  - 3~5점 차이: 근소 우세
  - 6점 이상: 의미 있는 차이
- 화면에 점수와 순위를 함께 제공하되, 근소 차이를 과장하지 않는다.

## AI 서술 출력 구조
AI 호출 시 원본 이름/생년월일시 대신 서버가 만든 익명화된 대상 ID와 계산 결과를 전달한다.

예시 출력 JSON 구조:
```json
{
  "rankingSummary": "...",
  "candidates": [
    {
      "candidateId": "candidate_1",
      "oneLine": "...",
      "strengths": ["...", "..."],
      "cautions": ["..."],
      "practicalTip": "..."
    }
  ],
  "situationalWinners": {
    "communication": "candidate_2",
    "emotionalStability": "candidate_1",
    "longTerm": "candidate_3"
  },
  "finalSummary": "..."
}
```

## 저장해야 할 스냅샷
구매 후 결과가 바뀌지 않도록 아래를 함께 저장한다.
- 상품키
- 관계 유형
- 대상 수
- 계산 엔진 버전
- 대상별 계산 결과
- 대상별 점수
- 랭킹 결과
- AI 모델명
- 프롬프트 버전
- 생성된 1:N 서술 JSON
- 생성 시각

## MVP 구현 범위
포함:
- 기준 1명 + 대상 2~5명
- 연인/친구/직장동료
- 종합 랭킹
- 비교 매트릭스
- 대상별 강점/주의점
- 상황별 추천
- AI 또는 템플릿 기반 설명

MVP에서 제외:
- 6명 이상 대규모 비교
- 그룹 전체의 집단 사주 분석
- 대상끼리의 N:N 상호 궁합
- 시간 흐름에 따른 월별/연도별 랭킹 변화

## 구현 완료 조건
다음 조건을 만족하면 1:N 기능을 구현 완료로 본다.
1. 2~5명의 입력을 검증할 수 있다.
2. 각 대상의 1:1 계산을 동일 엔진으로 수행한다.
3. 서버에서 비교 점수와 랭킹을 결정한다.
4. AI는 계산 결과를 바꾸지 않고 설명만 생성한다.
5. 결과 화면이 순위 + 매트릭스 + 대상별 해석 + 상황별 추천을 제공한다.
6. 3,000원 상품 결제가 검증된 주문에서만 생성된다.
7. 결과 스냅샷을 저장해 재조회 시 동일 결과를 제공한다.
