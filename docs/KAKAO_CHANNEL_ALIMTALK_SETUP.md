# 카카오톡 채널 알림톡 운영 설정

우리궁합의 결과 완료 알림은 Kakao Developers의 `나에게 보내기` API가 아니라 **카카오톡 채널 알림톡**으로 발송한다.

카카오 공식 안내상 주문·결제·서비스 이용 결과처럼 자동으로 보내는 정보성 안내는 알림톡이 적합하며, 알림톡은 공식 딜러사를 통해 사용한다. 현재 구현은 SOLAPI REST API를 사용한다.

## 1. 카카오톡 채널 준비

1. 카카오비즈니스에서 우리궁합 카카오톡 채널을 만든다.
2. 운영 가능한 비즈니스 채널 상태로 전환한다.
3. SOLAPI 계정을 만들고 본인/사업자 인증을 완료한다.
4. SOLAPI의 카카오톡 채널 관리에서 우리궁합 채널을 연동한다.
5. 연동 후 채널의 `pfId`를 확인한다.

## 2. 알림톡 템플릿 등록

SOLAPI에서 정보성 알림톡 템플릿을 등록하고 카카오 검수를 완료한다.

권장 본문:

```text
우리궁합 결과 생성이 완료됐어요.
보관함에서 구매한 결과를 확인해 주세요.
```

권장 버튼:

- 버튼명: `결과 확인하기`
- 유형: 웹링크
- 모바일/PC URL: `https://woorigunghap-uty7.vercel.app/account/reports`

현재 서버 코드는 승인된 **정적 템플릿**을 그대로 발송하므로 템플릿 변수를 요구하지 않는다. SMS 대체발송도 비활성화한다.

## 3. SOLAPI API 키 발급

SOLAPI 콘솔에서 API Key / API Secret을 발급한다. Secret은 GitHub, 채팅, 브라우저 코드에 넣지 않는다.

## 4. Vercel Production 환경변수

아래 4개를 Vercel 프로젝트의 Production 환경변수에 저장한다.

```text
SOLAPI_API_KEY=
SOLAPI_API_SECRET=
SOLAPI_KAKAO_PF_ID=
SOLAPI_KAKAO_TEMPLATE_ID=
```

기존 `KAKAO_TOKEN_ENCRYPTION_KEY`는 이용자가 입력한 알림용 휴대전화 번호를 DB에 암호화 저장하는 데도 사용하므로 유지한다.

환경변수 저장 후 새 Production 배포가 필요하다.

## 5. 사용자 흐름

1. 카카오 로그인 후 `보관함`으로 이동한다.
2. `카카오톡 채널 완료 알림`에서 휴대전화 번호를 입력한다.
3. 개인정보 저장 및 알림 발송 동의를 체크한다.
4. `채널 알림 받기`를 누른다.
5. 이후 구매한 리포트가 서버에서 완성되면 해당 번호의 카카오톡으로 우리궁합 채널 알림톡을 1회 발송한다.
6. 사용자는 언제든 `알림 해제`를 눌러 저장된 수신번호와 동의 상태를 삭제할 수 있다.

## 보안/개인정보

- 휴대전화 번호는 원문으로 DB에 저장하지 않고 AES-256-GCM으로 암호화한다.
- 휴대전화 번호는 AI에 전달하지 않는다.
- 서버 로그에 휴대전화 번호를 기록하지 않는다.
- 알림 해제 시 암호화된 번호와 동의 시각을 제거한다.
- 계정 삭제 시 사용자 행과 함께 제거한다.
- 알림톡 실패 시 SMS/LMS로 자동 대체하지 않는다.
