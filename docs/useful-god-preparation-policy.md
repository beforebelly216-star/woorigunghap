# 우리궁합 용신 판정 준비 엔진 v1

기준일: 2026-08-12  
상태: Day 6 항목 3-A 사용자 승인 / evidence 엔진 구현 완료 / 숫자 임계치 승인 대기

## 1. 목적

항목 3 `용신·기신 부합도`(romance/friend/coworker 모두 20점)를 계산하기 전에 각 개인 명식에서 용신 판정에 필요한 근거를 결정론적으로 산출한다.

이 단계에서는 **용신·희신·기신을 아직 확정하지 않으며 점수도 만들지 않는다.** 신강약·종격·조후·통관의 숫자 임계치를 실데이터 검증 전에 임의로 고정하지 않기 위함이다.

## 2. 승인된 판정 구조

1. 지장간·월령·통근·오행 구조 evidence 생성
2. 종격/특수구조 가능성 검토
3. 극단적 한난조습이면 조후 우선 검토
4. 강한 두 세력이 대립하고 중재 오행이 필요한 구조면 통관 검토
5. 위 예외가 아니면 억부를 기본 판정법으로 사용
6. 갈림 명식은 하나를 억지 확정하지 않고 복수 시나리오 대상으로 표시
7. 최종 `용신 / 희신 / 기신 / 판정법 / 신뢰도 / 근거`는 후속 승인된 규칙으로 산출

기존 Day 2의 `억부→조후→통관` 결정은 **일반 명식에서 억부를 기본값으로 사용하되, 조후·통관이 구조적으로 우선해야 하는 예외를 먼저 감지한다**는 의미로 구체화한다.

## 3. 현재 구현된 evidence

`src/lib/compatibility/useful-god-evidence.ts`

- 4주 천간/지지 전개
- 각 지지의 지장간(여기/중기/정기) 전개
- 일간의 정확한 천간 통근 위치
- 일간과 같은 오행 통근 위치
- 월/일/시지 기준 primary 통근 여부
- 천간 표면 오행 출현 횟수
- 지지 표면 오행 출현 횟수
- 지장간 오행 출현 횟수
- 절입 시각 기준 월령 사령 산출
- 출생시간 미상 시 00:00/23:59 사령 비교 후 안정/불확실 상태 기록
- 같은 입력의 evidence 반복 실행 동일성 보장

중요: 위 오행 횟수들은 **아직 하나의 세력 점수로 합산하지 않는다.** 월령·통근·지장간에 어떤 숫자 가중치를 줄지 승인 전이기 때문이다.

## 4. 월령 사령 기준

프로젝트 마스터 지침의 통용 일수 배분을 사용한다.

- 子·卯·酉(旺支): 여기 10일 / 정기 20일
- 午: 丙 10일 / 己 9일 / 丁 11일
- 寅·申·巳·亥(生支): 여기 7일 / 중기 7일 / 정기 16일
- 辰·戌·丑·未(庫支): 여기 9일 / 중기 3일 / 정기 18일

절입 순간부터 첫 24시간을 1일차로 계산한다. 실제 절기월이 30일을 초과하면 30일 이후는 정기(Main)가 이어지는 것으로 처리한다.

## 5. 출생시간 미상

원본 입력의 시주는 계속 `null`이다.

- 월주 자체가 시간에 따라 바뀌는 절입 경계일: `MONTH_PILLAR_UNCERTAIN`
- 하루 전체에서 월령 사령이 같음: `TIME_UNKNOWN_STABLE`
- 같은 날짜 안에서 사령이 달라질 수 있음: `TIME_UNKNOWN_UNCERTAIN`

후속 시주 12개 시나리오 엔진이 구현되면 각 시나리오에 동일 evidence 계산을 적용한다.

## 6. 의도적으로 미확정인 항목

현재 `methodDecision.selectedMethod = null`, `scoringReady = false`로 고정한다.

다음 항목은 사용자 승인 후에만 코드화한다.

- 월령/통근/지장간 세력 가중치
- 신강/중화/신약 경계값
- 종격 가능성 임계치
- 조후 우선 임계치
- 통관 우선 임계치
- 용신/희신/기신 매핑
- 두 사람 간 용신·기신 부합도 20점 산식

과거 문서의 `특정 오행 50% 이상`은 현재 **후보 규칙**으로만 남기고 아직 production 판정값으로 사용하지 않는다.

## 7. 검증

CI 명령:

```bash
npm run test:compatibility:useful-god-prep
```

현재 10개 표본에서 다음을 자동 검증한다.

- evidence 결정성
- 지장간/통근 데이터 존재
- 알려진 시간은 4주 사용
- 시간 미상은 시주를 임의 생성하지 않음
- 월령 사령 상태 기록
- 용신/희신/기신 및 최종 판정이 아직 비어 있음

기존 검증도 함께 유지한다.

- 만세력 골든 30/30
- 날짜·절입 경계 8/8
- 일간 100/100 순서쌍
- 일지 144/144 순서쌍
- lint
- production build
