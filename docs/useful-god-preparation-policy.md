# 우리궁합 용신 판정 준비 엔진 v1.1

기준일: 2026-08-12  
상태: Day 6 항목 3-A evidence 구현 완료 / 신강약 shadow v2 구현 완료 / production 승격 사용자 승인 대기

## 1. 목적

항목 3 `용신·기신 부합도`(romance/friend/coworker 모두 20점)를 계산하기 전에 각 개인 명식에서 용신 판정에 필요한 근거를 **AI API 없이 결정론적으로 산출**한다.

핵심 원칙:

- 사주 계산, 신강약, 용신 후보, 궁합 점수는 서버의 규칙 엔진이 계산한다.
- LLM은 점수를 만들거나 수정하지 않는다.
- AI API는 최종 결과를 자연어로 설명할 때만 선택적으로 사용한다.
- 같은 입력과 같은 계산 버전이면 항상 같은 결과가 나와야 한다.
- 불확실한 명식은 억지로 하나의 용신으로 확정하지 않고 시나리오/신뢰도로 관리한다.

따라서 수십·수백 명의 사용자가 동시에 있어도 핵심 점수 계산에 인당 AI API 호출이 필요하지 않는다.

## 2. 최신 판정 구조

기존의 `억부→조후→통관 중 먼저 걸리는 하나를 선택`하는 구조는 사용하지 않는다. 세 관점을 각각 계산한 뒤 종합한다.

1. 지장간·월령·월령사령·통근·오행 구조 evidence 생성
2. 원국 합충회합 및 실질 세력 보정
3. `得令(득령) / 得地(득지) / 得勢(득세)`로 일간 강약을 계산
4. `從格(종격)` 가능성은 별도 후보 규칙으로 검토
5. `扶抑(억부)`, `調候(조후)`, `通關(통관)` 후보를 각각 독립 계산
6. 세 방법이 같은 오행을 지지하면 confidence 상승
7. 서로 충돌하면 복수 후보 또는 갈림 케이스로 저장하고 confidence 하향
8. 최종 `용신 / 희신 / 기신 / 판정법 / 신뢰도 / 근거`를 구조화
9. 두 사람의 방향별 적합도를 `A가 B에게 10점 + B가 A에게 10점 = 20점`으로 계산

## 3. 용어와 기계화 원칙

### 3.1 得令(득령)

태어난 계절인 `月令(월령)`이 일간을 돕는지 보는 축이다.

- 월지 자체를 주 근거로 사용한다.
- `月令司令(월령사령)`은 보정 근거로 사용한다.
- 사령 하루 경계만으로 전체 신강약이 급변하지 않도록 한다.

### 3.2 得地(득지)

일간이 지지에 실제 뿌리를 두는지 보는 축이다.

- 일지만 보지 않고 년지·월지·일지·시지 전체의 `通根(통근)`을 본다.
- 같은 천간의 정확한 뿌리와 같은 오행의 뿌리를 구분한다.
- 지장간의 본기/중기/여기와 위치를 가중한다.
- `十二運星(십이운성)`은 v1에서 보조 evidence로만 사용하고 단독 판정권을 주지 않는다.

### 3.3 得勢(득세)

명식 전체에서 일간을 돕는 세력과 소모·제어하는 세력을 비교한다.

- `比劫(비겁)`과 `印星(인성)`은 지지 방향이다.
- `食傷(식상)`, `財星(재성)`, `官殺(관살)`은 소모·제어 방향이다.
- 천간과 지장간을 위치/역할별로 가중한다.
- 지지를 표면 오행으로 한 번 세고 지장간으로 다시 세는 이중계산은 피한다.
- 원국의 합화·삼합·방합 등 실질 세력 보정은 후속 단계에서 추가한다.

## 4. 현재 구현된 evidence

`src/lib/compatibility/useful-god-evidence.ts`

- 4주 천간/지지 전개
- 각 지지의 지장간(여기/중기/정기) 전개
- 일간의 정확한 천간 통근 위치
- 일간과 같은 오행 통근 위치
- 월/일/시지 기준 primary 통근 여부
- 천간 표면 오행 출현 횟수
- 지지 표면 오행 출현 횟수
- 지장간 오행 출현 횟수
- 절입 시각 기준 월령 사령 산출
- 출생시간 미상 시 00:00/23:59 사령 비교 후 안정/불확실 상태 기록
- 같은 입력의 evidence 반복 실행 동일성 보장

## 5. 월령 사령 기준

프로젝트 마스터 지침의 통용 일수 배분을 사용한다.

- 子·卯·酉(자·묘·유, 旺支 왕지): 여기 10일 / 정기 20일
- 午(오): 丙(병) 10일 / 己(기) 9일 / 丁(정) 11일
- 寅·申·巳·亥(인·신·사·해, 生支 생지): 여기 7일 / 중기 7일 / 정기 16일
- 辰·戌·丑·未(진·술·축·미, 庫支 고지): 여기 9일 / 중기 3일 / 정기 18일

절입 순간부터 첫 24시간을 1일차로 계산한다. 실제 절기월이 30일을 초과하면 30일 이후는 정기(Main)가 이어지는 것으로 처리한다.

월령사령은 절대 판정 스위치가 아니라 월지의 계절성을 미세 조정하는 보조 신호로 사용한다.

## 6. 신강약 shadow v2 — API 0회 기계화 실험

파일: `src/lib/compatibility/strength-candidate.ts`

현재 이 점수는 **고객 결과에 사용하지 않는 SHADOW_ONLY** 상태다.

### 6.1 세 축

- `得令(득령)` 35%
- `得地(득지)` 30%
- `得勢(득세)` 35%

각 축은 0~100의 확률이 아니라 **50을 중립으로 한 제품용 강약 지수**다.

### 6.2 득령 관계 지수

| 월령과 일간의 관계 | shadow 지수 |
|---|---:|
| 같은 오행 `比劫(비겁)` | 75 |
| 일간을 생하는 `印星(인성)` | 65 |
| 일간이 생하는 `食傷(식상)` | 45 |
| 일간이 극하는 `財星(재성)` | 40 |
| 일간을 극하는 `官殺(관살)` | 30 |

월지 자체 80%, 월령사령 20%로 계산한다.

### 6.3 득지 통근 지수

통근은 모든 지지를 본다.

위치 가중:

- 년지 0.55
- 월지 1.00
- 일지 0.90
- 시지 0.75

지장간 역할 가중:

- 여기 0.40
- 중기 0.65
- 본기 1.00

같은 일간 천간이면 1.00, 같은 오행의 다른 음양 천간이면 0.85를 곱한다.

`득지 지수 = 30 + 통근비율 × 70`

따라서 뿌리가 전혀 없더라도 이 축 하나만으로 전체 명식을 0점 처리하지 않는다.

### 6.4 득세 세력 지수

오행 관계별 세력 계수:

- 비겁 +1.0
- 인성 +0.8
- 식상 -0.6
- 재성 -0.8
- 관살 -1.0

천간과 지장간에 위치/본기·중기·여기 가중치를 적용해 `supportPower`와 `pressurePower`를 각각 계산한다.

`득세 = 50 + 50 × (support - pressure) / (support + pressure)`

### 6.5 shadow 등급 후보

- 0~34.9: VERY_WEAK
- 35~44.9: WEAK
- 45~55.9: BALANCED
- 56~70.9: STRONG
- 71~100: VERY_STRONG

이 임계치는 아직 production 확정값이 아니다.

| 1990-05-15 14:30 | 46.1 | BALANCED |

| 1995-11-11 11:11 | 53.7 | BALANCED |
| 1999-10-20 10:25 | 36.3 | WEAK |

## 8. API 비용 구조

핵심 계산 경로는 다음과 같다.

`입력 → 만세력 → evidence → 신강약 → 종격/억부/조후/통관 후보 → 용신·희신·기신 → 두 사람 20점 → 9항목 종합점수`

위 전 과정은 **LLM/API 호출 0회**로 구현한다.

AI는 필요할 경우 마지막 단계에서만 사용한다.

`확정된 계산Snapshot + 점수 + 근거 코드 → AI 자연어 서술 1회`

따라서 사용자가 늘어날 때 점수 계산 비용이 LLM 토큰 비용에 비례해서 증가하지 않는다. AI 설명 비용이 부담되면 `REPORT_NARRATIVE_MODE=template`로 템플릿 서술을 사용하고, 유료 결제 건에만 AI 서술을 실행할 수 있다.

## 9. 출생시간 미상

원본 입력의 시주는 계속 `null`이다.

- 월주 자체가 시간에 따라 바뀌는 절입 경계일: `MONTH_PILLAR_UNCERTAIN`
- 하루 전체에서 월령 사령이 같음: `TIME_UNKNOWN_STABLE`
- 같은 날짜 안에서 사령이 달라질 수 있음: `TIME_UNKNOWN_UNCERTAIN`

production 강약/용신 계산에서는 가능한 시주 12개 시나리오를 계산하고 중앙값과 범위를 사용한다. 두 사람 모두 시간 미상이면 궁합 계산 단계에서 최대 144개 시주 조합을 계산한다.

## 10. 아직 production 미확정인 항목

다음은 사용자 승인 또는 추가 검증 후에만 고객 점수에 반영한다.

- shadow v2 강약 가중치/등급 임계치의 production 승격
- 원국 합화·삼합·방합에 따른 실질 세력 보정
- 종격 후보 임계치
- 일간×월령 기반 조후 기준표
- 통관 후보 감지 기준
- 용신/희신/기신 최종 병합 규칙
- 두 사람 간 용신·기신 부합도 20점 산식

과거 문서의 `특정 오행 50% 이상`은 최종 종격 확정 규칙으로 사용하지 않는다.
