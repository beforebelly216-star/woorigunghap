# 우리사주 신강약 엔진 검증 기준 v1.1

기준일: 2026-08-12  
상태: Day 6 MVP 검증 기준

## 1. 목적

신강약을 학술적으로 완벽하게 증명하는 것이 아니라, 우리사주의 `용신·기신 부합도`가 큰 방향을 자주 뒤집지 않도록 **단순하고 재현 가능한 안전장치**를 만든다.

10개 표본의 분포가 보기 좋다는 이유로 기준을 채택하지 않는다. 10개는 코드가 정상 작동하는지 보는 sanity check일 뿐이다.

## 2. MVP 검증 규모

Day 15 베타 전에는 다음 수준으로 제한한다.

- 기존 자동 표본 10건: 반복 동일성/NaN/폭주 확인
- 독립 참조 사례 24~36건: `신약 / 중화·갈림 / 신강`의 큰 방향 확인
- 가능하면 10일간과 계절이 한쪽에만 몰리지 않도록 구성
- 종격·극단 편중 등 특수구조 몇 건을 별도 challenge 사례로 포함

100건 이상의 대형 Gold set과 360~1,000건 구조 스트레스 테스트는 베타 이후 고도화 백로그로 이동한다.

## 3. 판정 원칙

핵심은 정답률을 억지로 높이는 것이 아니라 **오판의 영향도를 줄이는 것**이다.

- 신강/신약 지수는 용신 후보를 정하는 `soft signal`로 사용한다.
- 경계 구간은 confidence를 낮춘다.
- confidence가 낮으면 용신·기신 적합도 점수를 70점 중립 방향으로 감쇠한다.
- 애매한 명식은 억지로 신강 또는 신약으로 확정하지 않는다.
- 특정 목표 분포에 맞추기 위해 가중치를 조정하지 않는다.

## 4. 참조 사례 사용법

참조 사례는 우리 산식으로 다시 라벨링하지 않는다.

가능한 경우 고전/해설 자료에서 신강·신약의 큰 방향이 명시된 사례를 사용하고, 해석이 갈리는 사례는 `AMBIGUOUS(갈림)`로 둔다.

MVP 통과 판단은 다음을 본다.

1. 같은 입력 반복 결과 동일 100%
2. `신강 ↔ 신약` 직접 반전이 소수인지
3. 경계/갈림 사례에서 confidence가 낮아지는지
4. 특정 일간·계절에 이유 없이 한 방향으로 몰리지 않는지

정확한 퍼센트 하나를 제품의 과학적 정확도로 표현하지 않는다.

## 5. production 적용 방식

현재 `strength-shadow-v2`의 35/30/35 지수는 사용자에게 직접 노출하는 절대 신강도 점수가 아니다.

실서비스 v1에서는 다음처럼 사용한다.

- `得令(득령)` 35%
- `得地(득지)` 30%
- `得勢(득세)` 35%
- 신약 후보: 45 미만
- 중화/갈림: 45~55.9
- 신강 후보: 56 이상
- 극단에서 멀수록 confidence를 낮춰 ③ 용신·기신 점수가 중립에 가까워지도록 한다.

이 방식은 잘못된 신강약 한 번이 궁합 총점 20점을 과도하게 뒤집는 것을 막기 위한 제품용 보수 규칙이다.

## 6. 베타 이후 고도화

실사용 데이터와 검증 시간이 확보되면 다음을 추가한다.

- 참조 사례 100건 이상
- 합화·삼합·방합 세력 보정 정교화
- 종격 전용 판정기
- 일간×월령 조후 기준표 정밀화
- 대규모 구조 스트레스 테스트
- 계산 버전별 결과 비교

## 7. 비용 원칙

신강약·용신 후보·궁합 점수 계산은 모두 서버 내부 결정론 규칙으로 처리하며 AI API를 호출하지 않는다. AI는 확정된 점수와 근거의 자연어 서술에만 선택적으로 사용한다.
