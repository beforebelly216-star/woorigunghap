# 우리궁합 1:1 유료 리포트 콘텐츠 계약 v1

이 문서는 1:1 유료 리포트에서 삭제하거나 임의 축약하면 안 되는 최소 콘텐츠 범위를 정의한다.

## 기본 정보 — AI 해설 전 필수 노출
- 두 사람 각각 년주·월주·일주·시주. 출생시간 미상은 시주를 `미상`으로 표시한다.
- 사주 원국의 겉오행 개수: 목·화·토·금·수.
- 지장간까지 반영한 실질 오행 세력 비중.
- 겉오행 개수와 실질 세력 비중이 다른 개념임을 사용자에게 안내한다.
- 단순 오행 개수만으로 신강약·용신·궁합을 판정하지 않는다.

## 필수 10개 챕터
1. 첫 화면 요약: 점수, 등급, 한 줄 총평, 4~5문장 상세 총평.
2. 나의 관계 원국: 기본 성향, 과잉/부족 기운, 관계에서 필요한 기운, 장점/주의점.
3. 상대방의 관계 원국: 2번과 동일한 깊이. 문장 복제 금지.
4. 두 사람의 기본 케미: 일간, 일지, 음양, 오행의 계산 근거와 현실 의미.
5. 실제 결속과 마찰: 천간 합충, 지지 형충파해, 귀인 등 실제 evidence와 생활 영역 연결.
6. 양방향 영향: A→B와 B→A를 분리하고 필요한 기운 보완과 부담 기운을 설명.
7. 관계 흐름: 역할, 주도권, 친밀해졌을 때, 최소 2개 현실 갈등 시나리오와 대응.
8. 관계유형 전용 분석: 짝사랑/썸/연인/친구/직장동료의 현실 행동 포인트 최소 3개.
9. 강점과 위험신호: 핵심 강점 2개 이상, 반복 마찰 2개 이상, 레드 플래그, 과장 없는 경고.
10. 실전 매뉴얼: 하면 좋은 것 3개 이상, 피할 것 2개 이상, 갈등 대응 3단계 이상, 추천 활동 3개 이상.

## 제외
- 세운·대운·특정 연도/월의 관계 타이밍 예측은 유료 리포트에서 제공하지 않는다.
- 내부 개발용 문자열(WEAK, STRONG, soft signal, confidence, payload, engine 등)을 사용자에게 노출하지 않는다.
- AI가 점수·순위·새로운 합충 사실을 만들거나 변경하지 않는다.

## 분량과 품질
- Claude 프롬프트 목표: 전체 한국어 약 4,500~7,000자.
- 코드 품질 게이트: 지나치게 짧은 결과, 개인 챕터 부족, 갈등 시나리오/실전 항목 누락을 실패로 판정한다.
- 품질 게이트 실패 시 Claude를 1회 자동 재시도한다.
- 두 번째 시도까지 실패하면 짧은 템플릿을 유료 결과인 것처럼 조용히 노출하지 않고 재생성 안내를 제공한다.

## 설계 원칙
`계산 데이터 압축 ≠ 해석 정보 삭제`.
원본 생년월일·결제번호·대량 시나리오 원문은 Claude에 보내지 않되, 개인화에 필요한 파생 evidence는 충분히 제공한다.
