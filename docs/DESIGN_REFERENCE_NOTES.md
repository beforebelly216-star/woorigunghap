# UI/UX Reference Notes — 2026-08-25

Design Foundation v2를 만들 때 참고한 외부 제품의 원칙만 기록한다. 화면 복제용 문서가 아니다.

## Co–Star

차용: 강한 타이포그래피, 절제된 에디토리얼 감각, 전형적인 점술 장식 최소화.

주의: 과도한 텍스트 중심 화면과 약한 navigation은 그대로 따르지 않는다.

## The Pattern

차용: 관계 호환성을 요약 → trait → deeper insight로 단계화하는 progressive disclosure.

우리사주 적용: Relationship Label / Two Sides / 핵심 강점·주의점 → CH0~CH9 상세 리포트 순서.

## Toss

차용: 모바일에서 핵심 숫자·제목을 우선시키고, CTA를 명확히 분리하는 정보 위계.

주의: 우리사주를 핀테크 화면처럼 만들지 않는다. visual identity가 아니라 interaction hierarchy만 참고한다.

## Spotify Wrapped

차용: 개인 데이터를 스토리 장면으로 변환하고 결과 자체가 공유 가능한 형태가 되게 하는 방식.

우리사주 적용: 점수/백분위/관계 label을 첫 장면의 주인공으로 만들고 공유 카드와 결과 UI의 시각 문법을 통일한다.

## 공통 원칙

- 외부 제품의 고유 레이아웃, 그래픽, 카피를 직접 복제하지 않는다.
- reference는 디자인 결정을 설명하는 근거이지 구현 template이 아니다.
- 우리사주의 고유 visual signature는 실제 계산에 연결된 오행 데이터와 관계 데이터다.
